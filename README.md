# Parka
A parking reservation full-stack web app

Τρέξτε το docker στον υπολογιστή σας και ύστερα την εντολή docker-compose up --build

Γνωρίζω οτι το σάιτ είναι ελλιπές αναφορικά με κάποιες λειτουργικότητες αλλά σκοπεύω να το αναβαθμίσω μόλις μου δώσετε 
και εσείς το σχετικό input.

Επίσης σκοπεύω να βάλω stripe για πληρωμές και google maps api για τις τοποθεσίες, καθώς και google api για log in με gmail
